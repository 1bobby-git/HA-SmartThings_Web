# 조명·Home Monitor 상태 전달 수정 — 1.8.24

## 수정 범위

기준은 main `9fe362fc2f06bbc06a5c4545afce6edfe8930833`의 1.8.23 소스다.
사용자 오류는 `command_queue_timeout`, `command_confirmation_timeout`이며, 실제 기기 로그와 합성 재현 결과를 혼동하지 않는다.

### 조명 확인

예를 들어 전원 on, 밝기 50, hue 0인 조명에 채도만 20 → 100으로 바꾸면
기존 코드는 변경하지 않은 on/50/0에도 새 값 또는 새 시각을 요구했다.
이제 전체 목표값 일치와 변경한 멤버의 새 증거를 확인한다.
색 모드를 요청했다면 색 관련 상태 또는 명시적 colorMode의 새 관찰이 필요하다.
밝기 이벤트만으로 같은 숫자의 색 모드 전환을 완료하지 않는다.
채도 0에서는 의미 없는 hue 갱신을 기다리지 않는다.

정확한 기기·위치·속성의 명령 후 조회, 기존 타임스탬프 순서, 오프라인/권한/다른 기기 차단은 유지한다.
색 모드를 보고하는 기기에서 그 모드가 요청과 명확히 다르면 스칼라 값이 맞아도 실패한다.
기존 묶음 제어의 허용 오차(0..100 값 0.5, 색온도 1 mired)를 개별 조명 명령에도 적용한다.
다른 도메인·보안 값 비교는 변경하지 않는다.
양의 안정화 시간이 설정된 경우 최신 조회도 그 시간을 지켜 완료하고, 반대 이벤트는 확인을 무효화한다.

### 대기와 화면 반영

기존 브리지의 기기별 직렬화와 10초 대기열 제한, 실제 확인 제한 시간은 유지한다.
시간 초과를 숨기거나 접수 응답을 성공으로 바꾸지 않는다.
상태 재조회가 켜진 기본 경로의 첫 조회 시작을 1,000ms → 250ms로 앞당긴다.
후속 조회는 기존 제한 횟수·직렬 실행·취소를 유지한다. 물리 기기 반응이 250ms라는 의미는 아니다.
HA가 확인 결과 sequence 이상과 일치하는 실제 조명 값을 받았다면
기존의 명령 후 전체 인벤토리 GET(최대 3초)을 생략한다.
SSE가 늦거나 값이 다르거나 중간 명령이 실패하면 기존 한 번의 보정 조회를 유지한다.

Home Monitor는 `alarm_state`와 `AlarmControlPanelState`를 사용한다.
집/외출 요청 중에는 arming, 해제 요청 중에는 disarming을 표시하며
`command_pending`, `confirmed_state` 속성으로 로컬 요청과 실제 관측값을 구분한다.
새 실제 상태가 들어오면 즉시 우선하고, triggered/pending 경보 상태는 숨기지 않는다.
실패·취소는 해당 요청의 진행 표시를 제거하고 실제 상태로 돌아간다.
이전 요청 완료가 더 새 요청의 표시를 지우지 않으며, 진행 표시 때문에 해제 요청을 차단하지 않는다.
명령별 단일 전달과 브릿지의 기존 직렬화를 유지한다.
삼성 서버의 설정/종료 지연을 우회하거나 요청값을 강제 armed 상태로 넣지 않는다.
HA 공식 계약: https://developers.home-assistant.io/docs/core/entity/alarm-control-panel/

## 검증 기록

수정된 테스트를 기존 1.8.23 동작 코드에 적용해 비교했다.
추가 조명 Node 회귀 11개 중 9개가 기존 코드에서 실패했고, 수정 후 11개가 모두 통과했다.
HA 조명에서 중복 조회 제거 회귀 2개가 기존 코드에서 실패했고 수정 후 통과했다.
Home Monitor 진행·취소·동시 명령 회귀도 추가했다.
전체 Node 1,377개(107 파일), Python unittest 391개가 수정 소스에서 통과했다.
Python 집계의 격리 테스트 1개 안에는 별도로 실행되는 조명 세부 테스트 48개가 포함돼 있다.
타입 검사·빌드·기존 CI/패키징도 릴리스 전에 실행한다.

검증은 합성 기기·격리 HA 테스트와 소스 수준이다. 사용자 HA에 실제 설치되었다거나
안방무드등의 물리 색/밝기/속도가 확인되었다고 주장하지 않는다.

## 업데이트

Bridge 앱과 HACS 통합을 모두 1.8.24로 맞추고 각각 재시작한다.
기존 로그인 데이터, 삼성 영구 프로필, 엔티티 ID를 삭제하지 않는다.
실환경에서는 전원 on/off, 밝기 20/80, 색온도 2700/4000K(기기 지원 범위),
빨강/파랑, Home Monitor 집/외출/해제의 실제 상태와 HA 표시를 비교한다.
Home Monitor 실환경 변경은 사용자가 안전한 상황에서 수행한다.
