# 0.1.163 Home Monitor

`my.smartthings.com` 대시보드의 위치별 Home Monitor 제어 경로를 보강한 릴리스입니다.

- `Home`과 추가 Location(예: `공유 오피스`)은 각각 자신의 Location 페이지와 Home Monitor 카드를 사용합니다.
- Home Monitor 카드를 연 뒤 열린 모달 내부에서만 `외출`, `재실`, `해제` 컨트롤을 찾습니다.
- `button`, `radio`, `tab` 형태와 `외출 중`, `재실 중`, `집에 있음` 등의 표시 변형을 처리합니다.
- 기존 `SECURITY_ARM_STATE_EVENT`의 timestamp 기반 순서 보호는 유지하여 오래된 이벤트가 최신 상태를 덮지 않도록 합니다.
- Home Assistant의 `alarm_control_panel`은 기존 위치 단위 `armAway`, `armStay`, `disarm` 명령을 그대로 사용합니다.
