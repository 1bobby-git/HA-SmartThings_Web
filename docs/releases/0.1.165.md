# SmartThings Web 0.1.165

Home Assistant의 Alarm Control Panel 기본 무장 코드 검사 때문에 `alarm_control_panel.home_monitor`와 `alarm_control_panel.exampleoffice_home_monitor` 명령이 Bridge에 도달하기 전에 차단되던 문제를 수정했습니다.

- `_attr_code_arm_required = False`
- `_attr_code_format = None`
- Home Assistant Core 서비스 진입 경로를 재현하는 회귀 테스트 추가
- 코드 없이 `armStay`와 `armAway` Location 명령이 Bridge까지 전달되는지 검증

0.1.164 이하 테스트는 통합 메서드를 직접 호출하여 Core의 사전 코드 검사를 재현하지 못했습니다. 0.1.165부터 실제 서비스 진입 경로를 검증합니다.
