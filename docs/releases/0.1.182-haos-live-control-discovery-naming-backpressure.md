# 0.1.182 HAOS 실환경 후속 수정

`0.1.181` 실환경 로그에서 Home Monitor 제목은 정확히 하나였지만 요청 모드는 없고 현재 모드 그룹만 하나 보였습니다. 카드 제목 대신 현재 모드 pill을 눌러 선택기를 여는 경로를 추가했습니다.

같은 Bridge의 Supervisor discovery 중복, 단일 Advanced 스위치의 `..._on` ID, 단일 재실센서의 `..._jaesil` ID, timestamp-only 상태 재발행과 HA 콜백 폭주도 함께 수정합니다.

Node 테스트·typecheck·build, Python 통합 테스트·compileall, API-free·secret·fixture 감사와 패키지형 HAOS runtime smoke를 모두 통과해야만 배포됩니다. 실제 계정의 Home Monitor 성공 여부는 설치 후 재확인이 필요합니다.
