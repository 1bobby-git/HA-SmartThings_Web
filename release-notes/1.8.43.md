- 삼성 로그인 페이지에서 `no_visible_auth_input`과 `login_required`가 반복될 때, 이전에 인증된 세션에 대해 별도 탭에서 Samsung Account → SmartThings 자동인증 복구 경로를 추가로 시도합니다.
- 입력창을 찾지 못한 미확정 페이지와 실제 비밀번호·이메일·OTP 입력 화면을 구분하며, 기존 사용자 입력 화면은 보존합니다.
- 보호된 HTTP 읽기와 실제 Location 앱 연결 검증을 모두 통과한 경우에만 복구된 탭으로 교체합니다.
- 반복 실패 시 재시도 간격을 기본값 기준 5 → 10 → 20 → 최대 30분으로 조정합니다. 최초 복구 지연은 유지하고 검증된 성공 시 초기화합니다.
- Bridge 앱과 Home Assistant 통합의 배포 버전은 1.8.43입니다. 통합 기능 변경 없이 기존 사람 수 카운터 0~100/증감 1, 장치·엔티티·사용자 설정 및 protocol 5 호환성을 유지합니다.
- 로그인 수정 적용에는 **Bridge 앱 1.8.43 업데이트가 필요합니다. HACS 통합만 업데이트하면 브리지 코드는 바뀌지 않습니다.** 기존 프로필과 세션 데이터는 삭제하지 마세요.
- 자동검증의 삼성 응답은 모의 데이터이며, 실제 계정의 장시간 유지가 확인된 것은 아닙니다. 삼성 서버가 세션을 폐기하거나 추가 인증을 요구하면 Bridge 웹 UI에서 다시 로그인해야 할 수 있습니다.
