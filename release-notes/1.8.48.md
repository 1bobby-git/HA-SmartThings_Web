- 센서/이벤트 및 상태 기반 숫자 엔티티의 ID를 현재 SmartThings 기기 이름과 실제 속성 타입으로 생성합니다. 화면의 한글 표시명과 ID 접미사를 분리하여 `열림 감지`는 `contact`, `배터리`는 `battery` 등으로 유지합니다.
- 복원 버튼의 ID 제안도 같은 규칙으로 보정하고, 기기 이름 변경 전의 자동 생성 ID와 잘못 번역된 자동 생성 ID를 현재 이름 기준으로 변경합니다. 사용자 지정 이름/ID와 다른 기기의 ID는 덮어쓰지 않으며 기존 unique_id를 유지합니다.
- 주기적인 로그인 유지 검사에서 Advanced HTTP 응답뿐 아니라 현재 Location 앱의 읽기 전용 연결까지 검증합니다. Advanced가 200이어도 Location 세션이 401이면 정상으로 표시하거나 정상 세션으로 저장하지 않습니다.
- 세션 갱신은 SmartThings의 실제 진입 경로로 시작합니다. 별도 Samsung Account 홈을 먼저 열어 경쟁하는 인증 흐름을 만들지 않습니다.
- 입력창이 보이지 않는 Samsung 인증 페이지를 즉시 닫고 새 SSO 페이지로 반복 교체하지 않습니다. 하나의 진행 중인 인증 페이지를 최대 2분간 유지하며, 완료 시 보호된 응답과 앱 연결을 모두 검증한 뒤 전환합니다.
- 대기가 끝나도 미완료인 인증 페이지는 사용자 확인용으로 보존하고 같은 페이지에서 무한 복구를 반복하지 않습니다. 비밀번호·OTP·Samsung loginId·계정 선택/계속 버튼·CAPTCHA 화면은 자동으로 입력하거나 건너뛰지 않습니다.
- 새 명령의 인증 거절을 뒤늦은 세션 검사 성공이 덮어쓰지 못하도록 검사 세대와 동시 실행 보호를 강화했습니다. 실제 계정의 장기 유지와 서버가 요구하는 재인증 여부는 설치 후 확인이 필요합니다.
- 엔티티 보정에는 HACS 통합 업데이트 후 Home Assistant 재시작이 필요하고, 세션 복구 개선에는 Bridge 앱 업데이트가 필요합니다. 자동 변경된 엔티티 ID를 직접 참조하는 자동화·대시보드 설정도 확인하세요.
