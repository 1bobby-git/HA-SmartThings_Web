## SmartThings 웹의 로그인 유지 설정 자동 적용

- 전용 브릿지 브라우저에서 SmartThings 설정의 `로그인 유지`를 실제 화면 조작으로 확인·활성화합니다. 이미 켜져 있으면 토글하지 않습니다.
- 페이지를 다시 열어 켜짐이 유지되는지 재확인하고, Location 앱의 읽기 전용 인증 검사까지 통과한 후보만 운영 탭으로 전환합니다. 설정 클릭만으로 로그인 성공으로 판정하지 않습니다.
- 현재 기기 제어와 Push를 담당하는 운영 탭은 직접 조작하지 않습니다. 화면 이탈·시간 초과·인증 실패 시 기존 운영 탭을 유지합니다. 설정만 확인하지 못했지만 후보의 인증이 정상인 경우 기존 갱신은 유지하고 설정 확인 필요로 표시합니다. 지원 데이터 접근, 세션 길이, 로그아웃, 비밀번호·OTP·계정 관리 설정은 변경하지 않습니다.
- 새 옵션 `keep_signed_in_enabled`는 전용 브릿지에서 기본 켜짐입니다. 앱 설정에서 끄면 자동 적용만 중단하며 SmartThings 웹에 저장된 설정을 강제로 끄지 않습니다. 직접 실행 환경은 `STW_KEEP_SIGNED_IN_ENABLED=false`로 중단할 수 있습니다.
- 시작 후 최초 인증 확인을 앞당겨 한 번 적용하고, 이후에는 기존 세션 갱신·복구 과정에서 새로 운영할 탭의 설정을 확인합니다. 별도의 고빈도 타이머나 기기 상태 폴링은 추가하지 않습니다.
- 브릿지 페이지에 `SmartThings 로그인 유지` 카드를 추가해 `켜짐 확인`, `확인 예정`, `설정 확인 필요`, `자동 적용 꺼짐`을 구분합니다. 개인 계정 정보나 쿠키 값은 표시·로그에 포함하지 않습니다.
- 엔티티 ID 수정, 흰색 UI, 로고, 한글, noVNC, 페어링, 인증 거절 및 프로토콜 변경 차단을 유지합니다.

### 적용과 검증 범위
Bridge 앱을 1.8.49로 업데이트하세요. 이 릴리스의 로그인 유지 변경은 Bridge에 있습니다. 통합 패키지도 1.8.49로 버전을 맞췄으며 통합의 기능 변경은 없습니다.

공식 웹 설정 설명상 브라우저가 실행 중인 동안의 로그인 유지이며, 브라우저 종료 후 인증 복원이나 서버 재인증 면제를 의미하지 않습니다. 설정 저장 및 프로필 재시작 회귀 테스트는 실제 Chromium의 격리된 합성 화면에서 수행합니다. 실제 Samsung 계정의 UI 적합성과 8시간·24시간 이상의 연속 로그인은 설치 환경에서 별도로 확인해야 합니다. UI 구조가 달라 자동 확인하지 못하면 성공으로 표시하지 않고 브라우저에서 설정을 확인하도록 안내합니다.
