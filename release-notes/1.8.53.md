## 로그인 유지: 실제 세션 검증과 같은 탭 갱신

- 설정 화면의 `stayLoggedIn`과 서버 응답이 반영된 실제 세션의 `stayLoggedIn`·만료 시간을 구분합니다. 새로운 **실제 로그인 세션** 카드에서 설정값, 실제 적용, 현재 남은 유효 시간을 확인할 수 있습니다.
- 로그인된 SmartThings 웹이 자연스럽게 생성한 클라이언트와 실제 액션을 재사용합니다. 정상 세션에서는 기존 탭을 유지하며, 설정 불일치나 만료 임박 시에만 보충 갱신을 요청합니다. 기존 웹 갱신이 진행 중이면 중복 요청하지 않습니다.
- 재인증 함수의 반환만으로 성공 처리하지 않습니다. 새로운 실제 세션 결과와 같은 페이지의 보호된 Location 읽기로 검증하며, **설정 적용**과 **만료 연장**을 구분합니다. 늦은 페이지·사용자 변경 결과는 폐기합니다.
- 보충 갱신은 진행 중인 기기 명령·확인 작업이 끝난 뒤 시작합니다. 기존 정상 탭은 먼저 닫지 않으며, 지원하지 않는 웹 구조·갱신 미확인 상황에는 기존의 검증된 브라우저 복구 경로를 유지합니다.
- `App settings → 설정`, `SmartThings for Web` 표기, 읽기 전용 `stayLoggedIn` 입력과 실제 `toggle-switch-stayLoggedIn` 버튼 구조를 인식합니다. 이미 켜진 스위치는 다시 누르지 않고, 설정창이 열려 있으면 읽기 전용으로 감지합니다. **상태 다시 확인**은 실제 브라우저 재검사를 요청합니다.
- 기능성 설정 저장 동의를 임의로 바꾸지 않습니다. 쿠키·인증 정보·계정 식별자는 새 진단에 포함하지 않으며, 별도 로그인 클라이언트를 만들지 않습니다. 기존 기기/엔티티 ID, 페어링, noVNC, 한글 UI와 쉐도우 없는 작은 radius 디자인을 유지합니다.

### 업데이트 및 확인

Bridge 앱을 1.8.53으로 업데이트하세요. 브릿지 내부 브라우저(noVNC)의 SmartThings 설정에서 **로그인 유지**를 켜 둡니다. 휴대폰·PC의 별도 브라우저 설정만으로 브릿지에도 적용되었다고 판단하지 마세요. 브릿지 화면에서 **실제 세션 유지 확인됨**을 확인합니다. 이미 켜 놓은 설정을 껐다 켜거나 계정을 삭제할 필요는 없습니다.

### 검증 범위

자동 테스트는 분리된 가상 상태와 로컬 응답으로 구성한 실제 Chromium을 사용합니다. 실제 Samsung 계정의 8시간·24시간 연속 유지나 재시작 후 인증 유효성을 보장하는 결과는 아닙니다. 서버가 재인증을 요구하거나 인증 화면이 나타나면 사용자 인증 화면을 보존합니다. 웹 내부 구조가 달라져 신호를 읽지 못하면 확인 불가로 표시하며 성공으로 간주하지 않습니다.
