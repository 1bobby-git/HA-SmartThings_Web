## 1.8.57

로그인 세션은 정상인데 외부에서 바뀐 기기 상태가 멈춰 보이는 경우의 상태 수신·복구 경로를 보완합니다.

- 로그인 확인 및 WebSocket 하트비트와 실제 기기 상태 이벤트 진행을 구분합니다. 실제 기기 이벤트 또는 전체 동기화가 2분 동안 없으면 기존 인증된 웹 조회 경로로 읽기 전용 전체 상태 동기화를 수행합니다. 정상 이벤트 수신 중에는 기존 정기 동기화 설정을 유지합니다.
- 푸시 준비 상태가 불완전해도 안전한 읽기 동기화와 재연결을 시도할 수 있습니다. 명령 실행·로그인 처리·세션 유지 작업·물리 동작 검증 중에는 보류하고, 중복 요청 병합과 실패 재시도 간격 제한을 적용합니다.
- 재연결 페이지 탐색이 성공했더라도 수신 프레임이 30초 안에 돌아오지 않으면 재시도합니다. 브라우저 종료 시 타이머와 늦은 완료 처리를 중단합니다.
- Playwright의 Page WebSocket 이벤트를 관찰하고 소켓 중복 연결을 방지합니다. 다른 작업 탭의 트래픽이 메인 상태 수신 탭의 생존 확인을 대신하지 않도록 범위를 제한합니다.
- `state_sync_watchdog` 진단을 추가합니다. 세션 쿠키를 초기화하거나 제어 명령을 재전송하지 않습니다.

Bridge 앱과 HACS 통합을 함께 1.8.57로 업데이트하세요. 상태가 조용한 동안에는 읽기 요청이 추가됩니다. 자동 테스트는 실계정의 장시간 유지 및 실제 기기 동작 검증과 구분되며, 이 릴리스만으로 사용자 HA에 자동 설치되지는 않습니다.
