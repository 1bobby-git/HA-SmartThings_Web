단일 스위치 명령 전송과 기기 상태 복구 경로를 보완합니다.

- 단일 `switch.on/off`도 다단계 조명과 동일하게 이미 로그인된 웹 앱의 `api/device` 서비스를 우선 사용합니다. 기존에는 단일 스위치만 이 경로를 건너뛰고 Advanced POST를 사용했습니다. 요청한 기기와 채널은 그대로 유지하며 다른 채널로 확장하지 않습니다.
- 앱 서비스가 전송 전에 없을 때만 기존 경로를 사용합니다. 전송 이후 오류·시간 초과에는 다른 경로로 명령을 재전송하지 않습니다. 응답 접수와 실제 상태 확인은 계속 구분합니다.
- 중복·재전송된 기기 이벤트는 상태 수신이 진행된 증거로 세지 않습니다. 고유 이벤트나 전체 동기화가 2분간 없으면 읽기 전용 복구를 시도합니다.
- 일부 센서의 계속된 이벤트가 다른 기기의 상태 누락을 가리지 않도록, 활성 수신 중에도 전체 읽기 동기화 간격을 최대 15분으로 제한합니다. 더 짧은 설정, 명령·인증·유지보수 중 보류, 중복 요청 병합과 실패 재시도 제한은 유지합니다.
- 더 오래된 Advanced 상태로 최신 Location 이벤트를 덮어쓰거나 HTTP 200만으로 성공 처리하지 않습니다. 보고된 두 타임스탬프를 사용한 회귀 검사를 추가했습니다.

Bridge 앱과 HACS 통합 버전은 1.8.58입니다. 자동 회귀 검사는 실제 물리 기기의 동작 확인이나 장시간 세션 검증을 대신하지 않습니다.
