단일 스위치의 전송 후 확인 대기 시간을 줄여 Home Assistant 제어 응답을 빠르게 합니다.

- 정확한 단일 `switch.on/off`가 Advanced `ACCEPTED` 영수증을 받은 경우 기존 상태 재조회 주기는 유지하면서, 첫 조회에서 명백한 오래된 응답 충돌을 식별합니다.
- 상태 조회가 요청한 값과 일치하더라도 그 타임스탬프가 현재 캐시보다 오래된 경우에는 성공 증거로 사용하지 않습니다. 대신 같은 오래된 값을 30초 동안 반복 조회하지 않고 즉시 `accepted_unconfirmed`로 반환해 Home Assistant 호출을 풀어줍니다.
- `accepted_unconfirmed`는 현재 엔티티 상태를 임의로 바꾸지 않습니다. 명령도 재전송하지 않으며 읽기 전용 전체 동기화를 백그라운드에서 요청합니다.
- 오래된 조회 충돌이 아닌 일반적인 확인 실패와 호출자가 명시적으로 timeout을 지정한 경우에는 기존 확인 정책을 그대로 유지합니다.
- 1.8.59의 `api/device` 앱 클라이언트 경로와 중복 전송 방지 정책은 유지합니다.

Bridge 앱과 HACS 통합 버전은 1.8.60입니다.
