# 1.8.65

SmartThings 로그인 뒤 `snapshot:device_cards:response_shape`가 표시될 수 있는 기기 카드 판별 경로를 보완합니다.

- 기기 저장소가 이미 처리하던 직접 카드 배열과 `data`로 감싼 배열·단일 카드 응답을 스냅샷 판별기도 인식합니다. `type`이 없는 카드는 첫 번째 `basic`·`cloud`·`camera` 객체에 기기 ID와 위치 ID가 있어야 합니다. 혼합된 잘못된 카드 목록, 다른 요청의 카드, 알 수 없는 오류 응답은 계속 차단합니다.
- 프로토콜 계약 버전 6은 이전 버전에서 저장된 불일치 판정을 새 관측으로 다시 검증하게 합니다. 오류 이력, 사용자 설정, 기존 별칭, 로그인 정보, Home Assistant 페어링은 유지합니다. 지금도 인식할 수 없는 응답이면 다시 차단됩니다.
- 애드온과 HACS 통합을 모두 1.8.65로 올리세요.

이 수정은 기존 코드의 응답 형식 지원 차이에 근거합니다. 해당 사용자 계정에서 실제로 받은 ACK는 확보되지 않아, 로그인 성공과 오류 해소는 아직 실기기로 확인하지 못했습니다.
