# 1.8.66

로그인 후 `snapshot:device_cards:response_shape`가 계속 표시되는 환경에서 원인을 확인할 수 있도록 **오류 진단 복사** 기능을 추가했습니다.

## 사용 방법

1. 오류가 발생한 사용자의 **SmartThings Web Bridge 앱을 1.8.66으로 업데이트**합니다.
2. Bridge 웹 UI를 열고, 오류가 표시된 상태에서 **오류 진단 복사**를 누릅니다. Home Assistant 통합과 페어링하기 전에도 사용할 수 있습니다.
3. 복사된 내용을 문제 신고에 첨부합니다. 자동 복사가 제한된 브라우저에서는 화면에 표시된 텍스트를 직접 복사합니다.

## 포함된 변경

- 응답 타입, 알려진 오류 코드, 카드 필드의 존재 여부를 요약합니다. 기기 이름·식별자 값·인증 정보·원문 메시지는 내보내지 않습니다.
- 실제로 형식 검사에서 거부된 응답의 구조를 오류 종류별로 저장해 재시작 후에도 확인할 수 있습니다.
- 이전 버전에 저장된 응답만 있으면 오류 원인으로 확정하지 않은 후보로 구분합니다. 저장 기록이 없으면 자료가 없음을 표시합니다.
- 진단은 상태를 읽기만 하며, 기록 실패가 기존 무결성 판정과 상태 전이를 방해하지 않도록 분리했습니다.
- Bridge 앱과 HACS 통합의 배포 버전은 1.8.66입니다. 진단 버튼은 Bridge 앱에 추가됩니다.

이번 릴리스는 보고된 다른 사용자 환경의 실패 응답을 확보하기 위한 진단 업데이트입니다. 그 환경에서 오류가 해결됐다고 확인한 버전은 아닙니다. 프로토콜 계약 6과 기존 오류 판정을 유지합니다.
