# 1.8.67

로그인 후 `find api/device`의 실제 응답이 정확히 `[null, null]`일 때, 이 응답을 기기 카드 형식 오류로 판단해 `snapshot:device_cards:response_shape`로 차단하는 문제가 있었습니다.

- 해당 요청에서 확인한 `[null, null]`만 데이터 없는 응답으로 건너뜁니다. 빈 기기 목록이나 동기화 완료로 처리하지 않으며 기존 기기와 정상 카드 개수를 보존합니다. 다른 잘못된 응답의 형식 검사는 계속 적용됩니다.
- 1.8.66에서 이 응답의 진단과 카드 형식 오류만 저장된 경우, 새 세션에서 모든 필수 스냅샷과 기기 이벤트를 오류 없이 다시 확인하면 해당 차단을 해제합니다. 다른 오류 이력과 변경 횟수는 보존하고 프로토콜 계약은 6을 유지합니다.

## 업데이트

1. Bridge 앱을 1.8.67로 업데이트하고 재시작합니다.
2. HACS 통합을 1.8.67로 업데이트합니다. Home Assistant가 재시작을 요청하면 재시작합니다.
3. 로그인 후 앱 버전과 연결 무결성을 확인합니다.

정상 카드 응답이 계속 오지 않으면 데이터 없는 응답만으로 준비 완료가 되지는 않습니다. 보고된 응답을 재현한 자동 검증과 실제 오류 사용자 환경의 업데이트 후 확인은 구분됩니다.
