# 1.8.68

Home Assistant 2026.11부터 `DeviceEntry.config_entries`는 폐기 예정 속성입니다. 이 속성을 읽을 때마다 Home Assistant는 호출한 통합을 찾으려고 콜스택 전체와 불러온 모듈 전체를 훑습니다. 통합은 오래된 기기 카드를 정리할 때 기기 레지스트리 **전체**를 돌면서 이 속성을 읽었습니다. 그래서 기기가 많은 설치(실측 818개)에서는 Home Assistant 이벤트 루프 CPU를 크게 썼습니다.

- 오래된 Bridge 기기 카드 정리는 이 설정 항목의 기기만 레지스트리 인덱스(`device_registry.async_entries_for_config_entry`)로 가져옵니다.
- 기기 소유 항목은 2026.11의 `config_entry_id`로 판단합니다. 이전 Core와 복원된 composite 기기는 지금처럼 `config_entries`를 씁니다. 방(영역) 동기화의 소유 판단도 같은 방식으로 바꿨습니다.
- 정리 규칙은 그대로입니다. 다른 설정 항목과 공유하는 기기는 지우지 않고 이 항목만 분리합니다. 위치(`loc_N`) 카드는 유지합니다.
- Bridge 코드는 바뀌지 않았습니다. 버전 정렬 규칙에 따라 Bridge 앱 버전도 1.8.68입니다.

## 업데이트

1. HACS 통합을 1.8.68로 업데이트하고 Home Assistant를 재시작합니다.
2. Bridge 앱도 1.8.68로 업데이트합니다(동작 변경 없음, 버전 정렬).

자동 검증(레지스트리 인덱스 사용, 폐기 예정 속성 미사용)과 실제 설치의 CPU 확인은 구분됩니다.
