# 1.8.69

Bridge 하나는 연결된 계정의 **모든 위치** 이벤트를 하나의 스트림과 하나의 순번으로 보냅니다. 위치마다 설정 항목을 따로 만들면 각 항목이 다른 위치의 상태 이벤트도 받습니다. 지금까지 통합은 이런 이벤트를 "자기 위치에 없는 기기"로 보고, 올 때마다 Bridge 인벤토리 전체를 다시 받아 파싱하고 복사했습니다. 위치 2개 설치에서 Home Assistant 이벤트 루프의 약 31%가 이 재처리에 쓰였습니다(HA 2026.11.0, 샘플링 측정).

- 다른 위치에 있는 알려진 기기의 상태 이벤트는 공유 순번만 앞으로 옮기고 버립니다. 그래서 이 위치의 다음 이벤트가 순번 누락으로 오인되지 않습니다.
- 순번 누락, 처음 보는 기기, 인벤토리 이벤트는 지금처럼 인벤토리 전체를 다시 받습니다. 기기가 위치를 옮기면 Bridge가 인벤토리 이벤트를 보내므로 그때 반영됩니다.
- Bridge 코드는 바뀌지 않았습니다. 버전 정렬 규칙에 따라 Bridge 앱 버전도 1.8.69입니다.

## 업데이트

1. HACS 통합을 1.8.69로 업데이트하고 Home Assistant를 재시작합니다.
2. Bridge 앱도 1.8.69로 업데이트합니다(동작 변경 없음, 버전 정렬).

자동 검증(다른 위치 이벤트에서 인벤토리 재요청 없음, 순번 연속성 유지)과 실제 설치의 CPU 확인은 구분됩니다.
