# 1.8.70

Bridge 앱의 브라우저 실행 환경을 Playwright 1.65.0으로 올렸습니다. Chromium은 151에서 158로 바뀝니다.

- `playwright-core` 1.65.0과 Bridge 이미지(`v1.65.0-resolute`, Chromium revision 1254)를 함께 올렸습니다. 둘 중 하나만 올리면 브라우저 실행 파일을 찾지 못해 Bridge가 시작되지 않습니다.
- setuid 샌드박스 경로와 AppArmor 프로파일을 새 revision에 맞췄습니다. arm64 이미지는 Chromium 경로가 `chrome-linux-arm64`로 바뀌었습니다.
- 통합 코드는 바뀌지 않았습니다. 버전 정렬 규칙에 따라 통합 버전도 1.8.70입니다. 프로토콜 계약은 6을 유지합니다.

## 업데이트

1. Bridge 앱을 1.8.70으로 업데이트하고 재시작합니다.
2. HACS 통합을 1.8.70으로 업데이트합니다(동작 변경 없음, 버전 정렬).
3. Bridge 웹 UI에서 로그인 상태와 연결 무결성을 확인합니다. 브라우저가 바뀌므로 다시 로그인해야 할 수 있습니다.

자동 검증은 amd64 이미지를 AppArmor 강제 없이 실행합니다. arm64와 Home Assistant OS가 적용하는 AppArmor에서의 동작은 자동 검증에 포함되지 않습니다.
