# 1.8.71

Home Assistant를 시작할 때마다 명령 전용 버튼·선택·숫자 엔티티가 사라지던 문제를 수정했습니다.

- 엔티티 레지스트리 정리 단계가 Advanced 카탈로그 명령 엔티티(`…_command_button_…`, `…_command_select_…`, `…_command_number_…`)와 관측된 선택 컨트롤 엔티티(`…_select_…`)를 현재 인벤토리의 엔티티로 인정하지 않아, 플랫폼이 만든 직후 지웠습니다. 이제 플랫폼이 만드는 것과 같은 규칙으로 고유 ID를 계산해 보존합니다.
- Bridge가 더 이상 내보내지 않는 컨트롤의 엔티티는 지금처럼 정리됩니다.
- Bridge 동작은 바뀌지 않았습니다. 버전 정렬 규칙에 따라 Bridge 앱 버전도 1.8.71입니다. 프로토콜 계약은 6을 유지합니다.

## 업데이트

1. HACS 통합을 1.8.71로 업데이트하고 Home Assistant를 다시 시작합니다.
2. 지워졌던 명령 전용 엔티티는 같은 고유 ID로 다시 만들어집니다. 엔티티 ID를 직접 바꿨거나 이름을 지정했던 경우 그 설정이 유지되는지는 Home Assistant가 삭제 기록을 보존하고 있는지에 따라 달라집니다.
3. Bridge 앱 1.8.71은 버전 정렬용이며 동작 변경이 없습니다.
