# 1.8.73

Home Assistant 실행 중 약 30분마다 버튼·이진 센서·조명 등이 한꺼번에 사라지던 문제를 수정했습니다.

- Bridge는 30분마다 상태를 다시 맞추면서 인벤토리 전체를 다시 적용하고, 명령 카탈로그와 기기 정보는 그 뒤에 비동기로 채웁니다. 그 몇 초 사이 통합의 엔티티 레지스트리 정리가 불완전한 인벤토리를 보고 명령 버튼, 읽기 전용 가전 전원 이진 센서 등을 지웠습니다.
- 플랫폼은 같은 실행 중에 이미 만든 엔티티를 다시 만들지 않기 때문에, 지워진 엔티티는 Home Assistant를 다시 시작할 때까지 돌아오지 않았습니다.
- 이제 삭제는 설정 직후 인벤토리가 준비된 첫 정리에서만 합니다. 실행 중의 정리는 엔티티 ID 이름 정리만 하고, 정말로 사라진 기기·엔티티는 다음 시작 때 정리합니다.
- Bridge 동작은 바뀌지 않았습니다. 버전 정렬 규칙에 따라 Bridge 앱 버전도 1.8.73입니다. 프로토콜 계약은 6을 유지합니다.

## 업데이트

1. HACS 통합을 1.8.73으로 업데이트하고 Home Assistant를 다시 시작합니다.
2. 재조정 때 지워졌던 엔티티는 재시작하면 같은 고유 ID로 다시 만들어지고, 이후 실행 중에는 지워지지 않습니다.
3. Bridge 앱 1.8.73은 버전 정렬용이며 동작 변경이 없습니다.
