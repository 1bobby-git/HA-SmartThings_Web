# 1.8.74

Bridge가 30분마다 상태를 다시 맞출 때 일부 컨트롤과 기기 종류가 흔들리던 문제를 수정했습니다.

- 새로고침 버튼: 재조정 스냅샷이 Advanced 새로고침 버튼을 만들고, 곧이어 명령 카탈로그 반영이 이를 지웠습니다. 그래서 새로고침 버튼 엔티티가 재조정마다 사라졌다가 다음 재조정에서야 돌아왔습니다. 이제 카탈로그 반영은 스위치 토글만 교체합니다.
- 기기 종류: Advanced 기기 행의 통신 방식 값(OCF, ZIGBEE 등)이 기기 카드의 종류(세탁기·건조기 등)를 덮어쓸 수 있었습니다. 이제 이 값은 종류가 비어 있을 때만 쓰고, presentation도 기존 값을 유지합니다.
- 통합 코드는 바뀌지 않았습니다(1.8.73의 실행 중 삭제 방지가 그대로 적용됩니다).

## 업데이트

1. Bridge 앱을 1.8.74로 업데이트합니다. 업데이트 중 Bridge가 다시 시작됩니다.
2. HACS 통합도 버전 정렬을 위해 1.8.74로 업데이트합니다. 통합 코드 변경은 없으므로 Home Assistant 재시작은 필요 없습니다.
