# 1.8.75

Bridge가 시작될 때마다 몇 시간 동안 CPU를 많이 쓰던 문제를 수정했습니다.

- 원인: 상세 조회(detail discovery)가 15초마다 기기 하나씩 SmartThings 페이지를 여는데, 시도 기록이 Bridge 시작마다 초기화되어 모든 기기를 다시 열었습니다. 기기 239대 기준 약 319회, 약 3시간 동안 Bridge CPU가 30~40%였습니다.
- 상세 컨트롤이 이미 완성된 기기는 다시 조회하지 않습니다(컨트롤은 저장된 인벤토리에서 복원됩니다).
- 2회 조회해도 완성되지 않은 기기는 `/data/detail-discovery.json`에 기록하고 7일 동안 또는 이름이 바뀔 때까지 다시 조회하지 않습니다. 기기 이름은 해시로만 저장합니다.
- 카메라 이미지 기기는 지금처럼 매번 조회합니다.
- 통합 코드는 바뀌지 않았습니다.

## 업데이트

1. Bridge 앱을 1.8.75로 업데이트합니다. 업데이트 중 Bridge가 다시 시작됩니다. 이 버전으로 처음 시작할 때는 미완성 기기를 한 번 더 조회하고, 그다음 재시작부터 조회가 줄어듭니다.
2. HACS 통합도 버전 정렬을 위해 1.8.75로 업데이트합니다. 통합 코드 변경은 없으므로 Home Assistant 재시작은 필요 없습니다.
