# 1.8.76

Bridge 컨테이너의 Node.js 보안 업데이트입니다.

- Node.js 24.22.1 → 24.22.3 (체크섬 검증). 2026-11-11 Node.js 보안 릴리스의 HTTP/2·TLS 취약점(CVE-2026-123864, CVE-2026-123877, CVE-2026-123872 외)을 반영합니다.
- nginx NGINX2Root(2026-11-18) 취약점은 Bridge 설정(평문 HTTP, HTTP/2·TLS·QUIC·resolver 미사용)에서 공개된 취약 경로에 해당하지 않습니다.
- 통합 코드와 Bridge 동작은 바뀌지 않았습니다.

## 업데이트

1. Bridge 앱을 1.8.76으로 업데이트합니다. 업데이트 중 Bridge가 다시 시작됩니다.
2. HACS 통합도 버전 정렬을 위해 1.8.76으로 업데이트합니다. Home Assistant 재시작은 필요 없습니다.
