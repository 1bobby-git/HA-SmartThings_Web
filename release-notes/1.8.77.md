# 1.8.77

Bridge의 자동 로그인 유지 설정 검사 안정성 수정입니다.

- 자동 로그인 유지 설정을 확인하는 첫 화면 검사의 시간 제한이 1.5초로 고정되어 있어, 기기가 많은 대시보드에서 느린 호스트일 때 `ui_timeout`으로 끝날 수 있었습니다. 이제 이후 단계와 같은 단계별 시간 제한(기본 3초, 최대 5초)을 씁니다.
- 검사 내용, 판단 방식, 화면 변경 동작은 바뀌지 않았습니다. 통합 코드도 바뀌지 않았습니다.

## 업데이트

1. Bridge 앱을 1.8.77로 업데이트합니다. 업데이트 중 Bridge가 다시 시작됩니다.
2. HACS 통합도 버전 정렬을 위해 1.8.77로 업데이트합니다. Home Assistant 재시작은 필요 없습니다.
