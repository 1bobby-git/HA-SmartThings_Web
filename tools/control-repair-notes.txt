## 1.8.20

- 공기청정기·팬의 전원 버튼 표시, 현재 상태, 명령 실행이 같은 컴포넌트·기능의 검증된 전원 항목을 사용하도록 수정합니다. 같은 전원의 action/detail 중복을 처리하되 모호한 대상이나 다른 컴포넌트를 임의 선택하지 않습니다.
- 실제 상태가 이미 켜짐인 조명의 밝기·색상·색온도 변경에서는 불필요한 전원 켜기 요청을 생략합니다. 꺼짐·알 수 없는 상태와 명시적 켜기 요청은 기존 전원 확인 경로를 유지합니다.
- 기기 명령 확인 시 전체 인벤토리를 반복 복제하지 않고 해당 기기의 정확한 상태만 읽도록 최적화합니다. 요청별 전송·접수·상태 조회·확인 실패 진단을 추가하며 원본 이름·식별자·인수·인증정보는 기록하지 않습니다.
- 상태 확인 제한과 안전 검사는 유지합니다. 시간 제한을 늘리거나 확인 실패를 성공으로 바꾸지 않으며, 요청값을 실제 상태로 저장하거나 명령을 자동 재전송하지 않습니다.
- Bridge 앱과 HACS 통합을 모두 1.8.20으로 업데이트 후 재시작하세요. 기존 엔티티 ID·로그인·방/재실·Home Monitor·Scene·TTS·짧은 README·의존성과 protocol 5는 유지합니다. 자동 검사와 실제 기기 정상화는 구분하며 실제 사용자 전구/스위치에는 접속하지 않았습니다.
