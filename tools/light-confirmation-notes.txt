## 1.8.19

- 조명 명령 후 상태 확인을 한 번의 초기 조회에 의존하지 않도록 수정합니다. 기본 30초 확인 시간 안에서 해당 기기의 읽기 전용 상태를 제한적으로 다시 조회하며, 성공·실패 후 조회를 중단합니다. 명령을 반복 전송하거나 제한 시간을 늘려 숨기지 않습니다.
- 색상·색온도 값을 다시 설정해 새 이벤트가 발생하지 않아도, 명령 접수 이후 시작된 해당 기기/위치/컴포넌트/기능의 실제 GET 응답과 현재 상태가 정확히 일치하면 상태 확인으로 처리합니다. 다른 기기의 이벤트, 누락된 상태, 오래된 조회, 단순 접수 응답은 성공 근거로 사용하지 않습니다. SSE 순서나 기기 타임스탬프를 만들어내지 않습니다.
- 조명 작업 종료 후 HA가 로컬 Bridge의 실제 상태를 한 번 동기화하여 실시간 스트림 지연과 일부 단계 실패 뒤의 실제 상태를 반영합니다. 실패는 그대로 알리고 입력값으로 상태를 덮어쓰지 않습니다.
- 반복 조작으로 대기 요청이 쌓이면 실행 전 10초 대기 한도에서 만료시켜 나중에 오래된 조작이 실행되지 않도록 합니다. 이미 전송 중인 명령은 중단하지 않습니다. 오류에는 전원·밝기·색상·색온도 중 실패한 단계를 표시합니다.
- Bridge 앱과 HACS 통합을 모두 1.8.19로 업데이트 후 재시작하세요. 기존 엔티티 ID·로그인·방/재실·Home Monitor·Scene·TTS·짧은 README·의존성과 protocol 5는 유지합니다. 실제 사용자 전구와 HA 연결 상태는 원격 검증하지 않았습니다.
